# Milestone plan and gates

|---|---|---|
| Tuần 9 đầu | Baseline, environment, DDL | Mapping đầy đủ và clean database build |

| Tuần 12 cuối | Rehearsal, peer evaluation, release | Mỗi người trả lời được SQL defense; release checklist |
